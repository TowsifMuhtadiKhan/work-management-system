# Desh TV branding

`desh-tv-logo.svg` is the red DESH TV wordmark with the yellow Bangladesh silhouette,
matching the reference provided by the project owner. It is stored locally so the app
does not depend on an external image host.

Source: https://commons.wikimedia.org/wiki/File:Desh_TV_logo_(2022-2026).svg
Original artwork: Desh TV. The source lists the asset as PD-logo; trademark rights remain
with the brand owner. The logo artwork is used unchanged.

Use the shared `BrandLogo` component for consistent proportions and a white background.
Primary actions use brand red, with yellow navigation and focus accents. Task status
colors remain semantic (green for completed, red for errors, etc.).
